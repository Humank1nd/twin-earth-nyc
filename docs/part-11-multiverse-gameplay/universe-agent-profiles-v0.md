## 1. Overview

Universe Agent Profiles define the cognitive and behavioral templates for entities residing
in or originating from modular universe packs. These profiles scale the baseline Earth‑1218
agent models to account for multiversal variations in perception, memory, and law adherence.

---

## 2. Cognitive Template Scaling

| Profile | Base Role | Logic Adjustments | MCU Diegetic Tag |
|---|---|---|---|
| **Sacred Resident** | Civilian | 1.0x perception; strict law compliance. | **Earth‑1218 Baseline** |
| **Incursion Variant** | Infiltrator | 1.5x awareness; high identity overlap risk. | **Skrull Simulation** |
| **Reality Weaver** | Operator | Bypasses local physics; low Institutional Heat. | **Chaos Magic** |
| **Cosmic Sentinel** | Guardian | Global field awareness; absolute Truth access. | **Heimdall Sight** |

---

## 3. Profile Invariants

Agents must adhere to the following invariants to maintain hub sacredness:
- **Identity Integrity** — variant overlap Sim must not exceed 0.9 in the hub.
- **Causality Cap** — exfil energy per agent is capped by the current translation gate bandwidth.
- **Aesthetic Bounds** — visual LOD must match the local slice fidelity (Part 9).

---

## 4. Diegetic Expansion

Agent profiles serve as “Asgardian registries”: identifying potential realm‑alignment
stress (Convergence) before it triggers a simulation‑wide REBOOT.
